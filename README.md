# Umi Protocol Frontend

**Project: Umi Protocol** 은 리액트(React) 기반의 인터랙티브 스토리텔링 웹 게임 프로젝트입니다.  
플레이어는 '솔피 힐링 클래스'라는 수상한 프로그램에 참가하여, 점차 물고기로 변해가는 신체적/정신적 변화를 겪으며 미지의 공간을 탐험하게 됩니다.

---

## 📖 스토리라인 (Storyline)

> **"5일 뒤, 당신은 솔피 님의 제물이 되어 위대한 물고기로 다시 태어날 것입니다."**

주인공은 오랫동안 사이비 종교 '우미교'와 교주 '전광어'를 추적해온 경찰관입니다.
상부의 수사 거부와 무시 속에, 홀로 결정적인 증거를 잡기 위해 '솔피 힐링 클래스'라는 명목으로 위장한 그들의 본거지인 외딴 섬에 잠입합니다.

하지만 그곳에서 마주한 진실은 예상보다 더 끔찍했습니다.
함께한 신도들은 모두 각기 다른 범죄를 저지르고 도망쳐온 범죄자들이었으며, 교주 전광어는 그들을 '솔피의 의식'을 위한 제물로 삼으려 합니다.

- 잠입 수사 (Undercover & Investigation): 당신은 광신도와 범죄자들 사이에서 정체를 숨기고, 그들의 자백과 증거를 수집해야 합니다.
- 5일의 제한 (Time Limit): 5일 뒤 열리는 의식의 제물 리스트에 당신의 이름이 올랐습니다. 그 전에 탈출하지 못하면 '완전한 물고기'가 되어 잡아먹히게 됩니다.
- 변이 (Mutation): 의도치 않게 섭취한 정체불명의 음료, 솔피의 눈물로 인해 시각과 언어 능력이 퇴화하며 점차 물고기로 변해가고 있습니다. `[뻐끔]`으로 마스킹되는 대화 속에서 진실을 파헤치세요.

## 👥 주요 인물 (Characters)

우미교에는 다양한 사연을 가진 5명의 주요 인물이 등장합니다. 이들과의 상호작용이 게임의 핵심입니다.

1.  **전광어 (교주)**
    - **특징**: 우미교의 창시자. 강한 신념과 카리스마로 신도들을 지배합니다.
    - **설계**: 그의 페르소나는 매우 견고하여 쉽게 흔들리지 않습니다. 기본적으로 어떠한 NPC보다 높은 Fish Level 5를 가지고 있어서 플레이어는 마스킹 로직으로 인해 대화하는것조차 쉽지 않으며, 그의 환심을 사기 위해서는 매일 열심히 그의 비위를 맞춰주어야 합니다.

2.  **이민어**
    - **특징**: 특종을 잡기 위해 잠입한 기자입니다. 과거 주인공의 인터뷰 자료를 통해 주인공이 경찰임을 이미 알고 있습니다.
    - **설계**: 주인공에게 먼저 접근하여 협력하거나 거래를 제안할 수 있는 일종의 협력자 NPC입니다. 하지만 그 역시 기자의 신분이기 때문에 자신의 이득을 위해서라면 주인공을 배신할 수도 있습니다.

3.  **박복어**
    - **특징**: 과거 살인을 저지르고 도망친 흉악범입니다. 현재는 교주의 오른팔로서 무력을 담당합니다.
    - **설계**: 전광어 만큼은 아니지만 높은 Fish Level, Faith를 가지고 있습니다. 플레이어는 그와 대화하며 환심을 사 전광어의 방에 들어갈 직접적인 아이템을 얻어내야 합니다.

4.  **청갈치**
    - **특징**: 화려한 언변을 가진 사기입니다. 사람들의 환심을 잘 사고, 다른 신도들의 비밀 정보를 쥐고 있습니다.
    - **설계**: 페르소나가 다른 의미로 견고합니다. 그는 faith도 낮고, fish level도 낮은 철저한 실리주의자입니다. 플레이어가 대화하며 다른 NPC들의 핵심적인 단어들, 스탯에 영향을 주는 단어들을 얻어내야 합니다.

5.  **곽빙어**
    - **특징**: 주인공과 같은 방을 쓰는 룸메이트이자 좀도둑입니다.
    - **설계**: 가장 쉽게 대화하고 마주칠 NPC입니다. 일종의 튜토리얼로서 그의 환심을 사는 과정이 곧 다른 NPC들과 대화할 전략을 세울 기준이 됩니다. 매일 그의 인벤토리에는 다른 NPC들의 물건들이 랜덤하게 들어갑니다. 호감도를 올려 그에게서 물건을 얻어내야 합니다.

## 🏆 승리 조건 (Victory Conditions)

**"5일 안에 섬을 탈출하십시오."**

1.  **신뢰와 정보 수집**: NPC들과 대화하여 친밀도를 높이고, 그들이 숨기고 있는 **증거와 정보**를 빼내야 합니다.
2.  **탈출 수단 확보**: 최우선 목표는 섬을 나갈 수 있는 보트 키(Boat Key)를 손에 넣는 것입니다.
3.  **타임 리밋**: 5일이 지나면 '솔피의 의식'이 시작되며, 주인공은 제물이 되어 게임 오버(Game Over)됩니다.
4.  **트롤 레벨**: 가드레일 에이전트, GA는 유저가 게임을 파괴할 의도가 있는지 실시간으로 검수합니다. NPC들의 자아를 흔드려는 행위, 게임의 흐름을 방해하고 룰을 벗어나는 행위를 감지해 레벨을 올려, 게임오버 혹은 즉시 일정을 종료시키는 패널티 역할을 합니다.

## 🎮 게임플레이 및 튜토리얼 (Gameplay & Tutorial)

이 게임은 스마트폰 인터페이스(Phone UI)와 현장 1인칭 시점(Scene View)이 결합된 듀얼 뷰(Dual-View) 방식을 채택하고 있습니다.

### 1. 게임 시작 (Getting Started)

1. 메인 화면의 스마트폰에서 게임 시작 메뉴로 진입해, 게임 세이브를 고르거나 새로 시작합니다. (최초 튜토리얼에서는 통신 기록 등을 확인할 수 있습니다.)
2. 튜토리얼을 진행하며 기본 조작과 상태 변화를 배웁니다.
3. 튜토리얼을 완료하면 본격적인 5일간의 생존과 조사가 시작됩니다.

### 2. 인터페이스 (Interface)

- **스마트폰 (Left/Center)**: 플레이어의 주요 인게임 도구입니다.
  - **Messenger**: 외부와 연락을 시도하거나 게임 초반 상황을 인식하는 용도로 사용됩니다.
  - **Map**: 현재 위치(Room, Floor)를 확인합니다.
  - **Inventory**: 획득한 아이템을 확인합니다. NPC와의 대화에서 아이템을 제시(LLM 전달)하여 특별한 반응을 이끌어내거나, 플레이어 자신이 소모해 스탯을 변화시킬 수 있습니다.
  - **Recorder/Credits**: 기록을 저장하거나 게임 크레딧을 확인합니다.
  - **Settings**: 음량 조절을 하거나, 재생되는 BGM/SFX를 조절합니다.

- **맵 UI (Scene View)**: 현재 플레이어가 위치한 공간입니다.
  - 모든 맵에는 상호작용 가능한 오브젝트(Move, Item, Info)와 NPC가 배치되어 있습니다.
  - **이동 및 엿듣기 (Eavesdrop)**: 다른 방으로 이동하려 할 때 NPC들이 모여 대화 중이라면 그 대화를 방 밖에서 엿들을 수 있습니다. 끼어들거나 계속 엿듣는 선택지에 따라 소모되는 행동력(HP/비용)과 전개가 달라집니다.
  - **잠긴 구역 (Locked)**: 특정 아이템이나 조건을 만족하지 않으면 입장할 수 없는 방이나 오브젝트가 존재합니다.

### 3. 물고기 레벨 (Fish Level)

- 플레이어의 돌연변이 상태를 나타내는 지표입니다.
- 레벨이 올라갈수록 스마트폰 화면에 물기, 이끼, 균열 등의 시각적 효과가 강력해지며(FishEyeEffect, UI 글리치)
- 플레이어의 물고기 레벨이 NPC보다 낮으면, 텍스트 일부가 `[뻐끔]`으로 마스킹되어 NPC와의 원활한 대화가 어렵습니다. 플레이어는 자신이 물고기 레벨을 높여서 대화를 원활하게 할 것인지, 맵 오브젝트 탐색을 불편하게 할 것인지 선택하게 합니다.

### 4. 대화 스탯

- 각 NPC는 **Faith, Fish Level, Friendly** 스탯을 가지고 있으며, 이는 플레이어와의 대화, 아이템 제시, 답변의 질에 따라 유동적으로 변화합니다.
- 대화 스탯이 일정 수치 이상에 도달하면 NPC가 핵심 정보를 누설하거나, 숨겨진 스토리, 중요 아이템 등 게임의 진행에 영향을 미치는 이벤트를 발생시킵니다.

## 🎨 디자인 및 게임플레이 철학 (Design & Philosophy)

이 프로젝트는 단순한 텍스트 어드벤처를 넘어, **유저가 직접 스토리에 개입하고 결과를 만들어내는 경험**을 지향합니다.

1.  **반응성 인터페이스**
    - 플레이어가 조작하는 스마트폰 화면은 주인공의 1인칭 시점을 그대로 구현합니다.
    - 게임의 진행도나 주인공의 신체적/정신적 상태 악화(Fish Level 상승)에 따라 화면 왜곡, 터치 불가, 노이즈 등 인터페이스의 실시간 퇴화를 경험하며 몰입감을 극대화합니다.

2.  **의사소통의 제약**
    - 완벽한 정보 전달을 의도적으로 배제합니다. 핵심 단서가 `[뻐끔]`으로 치환되거나 맵 뷰에서 시각적인 방해 요소가 적용됩니다.
    - 플레이어는 불완전한 힌트를 조합해 상황을 추론하고 유추해야 합니다.

## 🛠 개발 스택 (Tech Stack)

### Core

- **Framework**: React 19 (+ Vite)
- **Language**: JavaScript (ESModules)
- **Styling**: Tailwind CSS, PostCSS

### Libraries & Tools

- **Animation**: `framer-motion` (UI/Scene 전환 및 스마트폰 인터랙티브 애니메이션), `react-type-animation` (텍스트 타이핑 효과)
- **Audio**: `howler`, `use-sound` (오디오 효과음 및 BGM 처리)
- **Icons**: `lucide-react`
- **Linting**: ESLint

### Backend Integration

- **API 연결**: 실제 백엔드 API 서버를 연동하여 AI 채팅(LLM), 인증, 게임 상태 저장, 맵 관리 등을 종합적으로 처리합니다. (`src/api/*`)
- **생성형 AI**: LLM을 통해 NPC들의 성격(페르소나)에 맞는 실시간 응답을 생성하여 정해진 선택지 외의 다채로운 대화가 가능합니다.

## 📂 프로젝트 구성 (Structure)

```text
d:\Github\Frontend\src
├── api/             # 백엔드 API 통신 모듈 (auth, chat, item, map, stats 등)
├── assets/          # 이미지, 폰트, 오디오 등 정적 에셋
├── components/      # 재사용 가능한 UI 컴포넌트
│   ├── apps/        # 스마트폰 내부 앱 (Messenger, Map, Inventory, Recorder 등)
│   ├── ChatBubble.jsx, FishEyeEffect.jsx, MapInteractiveLayer.jsx 등 다수
├── context/         # 전역 상태 관리 (GameContext)
├── hooks/           # 커스텀 훅 (오디오, 게임 틱 등)
├── scenes/          # 주요 장면 화면
│   ├── MainMenuScene.jsx, MainGameScene.jsx, TutorialScene.jsx, EndingScene.jsx 등
├── utils/           # 유틸리티 함수
├── App.jsx          # 전체 레이아웃 및 라우팅 (Scene 전환 관리)
└── main.jsx         # 진입점
```

## 🚀 실행 방법 (Installation & Run)

이 프로젝트는 Vite를 기반으로 하며 백엔드 서버가 별도로 실행 중이어야 완벽한 게임 플레이가 가능합니다. 

```bash
# 프로젝트 설치
npm install

# 개발 서버 실행
npm run dev
# 기본 Port: 5173 
```

브라우저에서 `http://localhost:5173` 으로 접속하여 게임을 플레이할 수 있습니다.
