# Umi Protocol Frontend

**Umi Protocol**은 리액트(React) 기반의 인터랙티브 스토리텔링 웹 게임 프로젝트입니다.  
플레이어는 '솔피 힐링 클래스'라는 수상한 프로그램에 참가하여, 점차 물고기로 변해가는 신체적/정신적 변화를 겪으며 미지의 공간을 탐험하게 됩니다.

---

## 📖 스토리라인 (Storyline)

> **"5일 뒤, 당신은 솔피 님의 제물이 되어 위대한 물고기로 다시 태어날 것입니다."**

주인공은 오랫동안 사이비 종교 **'우미교'**와 교주 **'전광어'**를 추적해온 **경찰관**입니다.
상부의 수사 거부와 무시 속에, 홀로 결정적인 증거를 잡기 위해 **'솔피 힐링 클래스'**라는 명목으로 위장한 그들의 본거지인 외딴 섬에 잠입합니다.

하지만 그곳에서 마주한 진실은 예상보다 더 끔찍했습니다.
함께한 신도들은 모두 각기 다른 범죄를 저지르고 도망쳐온 범죄자들이었으며, 교주 전광어는 그들을 **'솔피의 의식'**을 위한 제물로 삼으려 합니다.

- **잠입 수사 (Undercover & Investigation)**: 당신은 광신도와 범죄자들 사이에서 정체를 숨기고, 그들의 **자백과 증거**를 수집해야 합니다.
- **5일의 제한 (Time Limit)**: 5일 뒤 열리는 의식의 제물 리스트에 당신의 이름이 올랐습니다. 그 전에 탈출하지 못하면 **'완전한 물고기'**가 되어 잡아먹히게 됩니다.
- **변이 (Mutation)**: 의도치 않게 섭취한 약물로 인해 시각과 언어 능력이 퇴화하며 점차 물고기로 변해가고 있습니다. `[뻐끔]`으로 마스킹되는 대화 속에서 진실을 파헤치세요.

---

## 👥 주요 인물 (Characters)

우미교에는 다양한 사연을 가진 5명의 주요 인물이 등장합니다. 이들과의 상호작용이 게임의 핵심입니다.

1.  **전광어 (교주)**
    - **특징**: 우미교의 창시자. 강한 신념과 카리스마로 신도들을 지배합니다.
    - **공략**: 그의 페르소나는 매우 견고하여 쉽게 흔들리지 않습니다.

2.  **이민어**
    - **특징**: 특종을 잡기 위해 잠입한 기자입니다. 과거 주인공의 인터뷰 자료를 통해 주인공이 경찰임을 이미 알고 있습니다.
    - **역할**: 주인공에게 먼저 접근하여 협력하거나 거래를 제안할 수 있습니다.

3.  **박복어**
    - **특징**: 과거 살인을 저지르고 도망친 흉악범입니다. 현재는 교주의 오른팔로서 무력을 담당합니다.
    - **위험도**: 매우 높음.

4.  **청갈치**
    - **특징**: 화려한 언변을 가진 **사기꾼**입니다. 사람들의 환심을 잘 사고, 다른 신도들의 비밀 정보를 쥐고 있습니다.

5.  **곽빙어**
    - **특징**: 주인공과 같은 방을 쓰는 **룸메이트**이자 좀도둑입니다.
    - **역할**: 도벽이 심해 열쇠 등 유용한 아이템을 방으로 가져옵니다.

## 🏆 승리 조건 (Victory Conditions)

**"5일 안에 섬을 탈출하십시오."**

1.  **신뢰와 정보 수집**: NPC들과 대화하여 친밀도를 높이고, 그들이 숨기고 있는 **증거와 정보**를 빼내야 합니다.
2.  **탈출 수단 확보**: 최우선 목표는 섬을 나갈 수 있는 **보트 키(Boat Key)**를 손에 넣는 것입니다.
3.  **타임 리밋**: 5일이 지나면 '솔피의 의식'이 시작되며, 주인공은 제물이 되어 게임 오버(Game Over)됩니다.

## 🎮 게임플레이 및 튜토리얼 (Gameplay & Tutorial)

이 게임은 **스마트폰 인터페이스(Phone UI)**와 **현장 1인칭 시점(Scene View)**이 결합된 듀얼 뷰(Dual-View) 방식을 채택하고 있습니다.

### 1. 게임 시작 (Getting Started)

1.  메인 화면의 스마트폰에서 **Start** 앱을 실행합니다.
2.  **[참가자 권리 포기 및 양도 각서]**가 나타납니다.
3.  내용을 확인(체크박스)하고 **'서명 및 입장'**을 클릭하면 게임이 시작됩니다.

### 2. 인터페이스 (Interface)

- **스마트폰 (Left/Center)**: 플레이어의 주요 도구입니다.
  - **Messenger**: NPC(주최 측, 알 수 없는 조력자 등)와 대화합니다. 스토리가 진행되는 핵심 채널입니다.
  - **Map**: 현재 위치(Room, Floor)를 확인하고 다른 장소로 이동합니다.
  - **Inventory**: 획득한 아이템을 확인합니다.
  - **Settings / Apps**: 다양한 미니 앱들을 통해 퍼즐을 풀거나 정보를 얻습니다.
- **메인 씬 (Background/Right)**: 현재 플레이어가 위치한 공간입니다.
  - NPC와의 조우, 이벤트 컷신 등이 이 화면에서 펼쳐집니다.

### 3. 물고기 레벨 (Fish Level)

- 플레이어의 상태를 나타내는 지표입니다.
- **Fish Tier**가 올라갈수록 스마트폰 화면에 물기, 이끼, 균열 등의 시각적 효과가 강화됩니다.
- 텍스트가 외계어처럼 보이거나 `[뻐끔]`으로 대체되어 의사소통이 어려워질 수 있습니다.

## 🎨 디자인 및 게임플레이 철학 (Design & Philosophy)

이 프로젝트는 단순한 텍스트 어드벤처를 넘어, **UI 자체가 스토리텔링의 일부가 되는 경험**을 지향합니다.

1.  **Diegetic UI (다이에제틱 인터페이스)**
    - 플레이어가 조작하는 스마트폰 화면은 게임 내 주인공이 실제로 보고 있는 화면입니다(1인칭 시점).
    - 주인공의 신체적/정신적 상태(Fish Level)가 악화됨에 따라 화면에 노이즈가 끼거나, 터치가 먹통이 되는 등 **인터페이스의 퇴화**를 통해 몰입감을 높입니다.

2.  **의사소통의 제약 (Communication Constraints)**
    - 완벽한 정보 전달을 거부합니다. 중요한 단서가 `[뻐끔]`으로 마스킹되거나, 글리치(Glitch) 효과로 인해 왜곡됩니다.
    - 플레이어는 불완전한 정보 속에서 상황을 유추하고 판단해야 합니다.

3.  **불확실성의 공포 (Horror of Uncertainty)**
    - 명확한 적이나 점프 스케어보다는, 알 수 없는 두려움과 서서히 조여오는 압박감을 중시합니다.
    - 익숙한 스마트폰 UI가 낯설고 기괴하게 변해가는 과정 자체가 공포 요소로 작용합니다.

## 🛠 개발 스택 (Tech Stack)

### Core

- **Framework**: React 19 (+ Vite)
- **Language**: JavaScript (ESModules)
- **Styling**: Tailwind CSS, PostCSS
- **State Management**: React Context API (`GameContext`)

### Libraries & Tools

- **Animation**: `framer-motion` (UI/Scene 전환 및 인터랙티브 애니메이션), `react-type-animation` (텍스트 타이핑 효과)
- **Icons**: `lucide-react`
- **Linting**: ESLint

### Backend (Mock)

- **Mock Backend**: 별도의 Node.js 서버로 실행되며, AI 채팅 응답 시뮬레이션 및 게임 상태(Stats) 관리를 담당합니다. 이 프로젝트는 실제 LLM에 의존하지 않고 개발할 수 있도록 설계되었습니다.

## 🚀 실행 방법 (Installation & Run)

이 프로젝트는 **Frontend**와 **Mock Backend**를 동시에 실행해야 정상적으로 작동합니다. 두 개의 터미널을 사용하세요.

### 1. Mock Backend 실행

```bash
cd mock-backend
npm install
npm run dev
# Port: 3000
```

### 2. Frontend 실행

```bash
# 프로젝트 루트 경로에서
npm install
npm run dev
# Port: 5173 (기본값)
```

브라우저에서 `http://localhost:5173`으로 접속하여 확인합니다.
